# Humanizer Skill

Guidelines for natural, human-centered UI copy and authentic user communication.

## 1. Remove Robotic AI Buzzwords
- **Avoid**: "Unlock your potential", "Empower your journey", "Cutting-edge solution", "Seamlessly leverage", "World-class experience".
- **Use**: Clear, honest, direct phrasing (e.g., "Learn Quran, Islamic Sciences & Modern Skills in a Safe Environment", "Explore Courses", "Download Class Notes").

## 2. Warm, Respectful & Empathetic Tone
- Speak directly to the student or parent with clarity and respect.
- For Islamic educational institutions, use authentic, traditional honorifics (ﷺ) and clear descriptions of course offerings.
- Keep button labels action-oriented and clear (e.g., "Apply for Admission", "Watch Recorded Lecture", "Download PDF Notes", "View Fee Details").

## 3. Micro-Copy Clarity
- Place helpful micro-copy near forms (e.g., "Takes 2 minutes • Female Teachers Only • Direct WhatsApp Confirmation").
- Provide unambiguous status tags (e.g., "Admission Open", "Live Class Active", "Fee Payment Verified").
