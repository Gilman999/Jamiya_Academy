# Impeccable Design Skill

Guidelines to create handcrafted, high-grade frontend interfaces and eliminate AI design "slop".

## 1. Eliminate AI Tropes & Slop
- Avoid generic AI color schemes (e.g. purple gradients on pure black `#000`, uniform muted beige surfaces, or default uninspired indigo/slate).
- Avoid "cards inside cards" soup. Use clean white space, subtle border divider lines, and typographic hierarchy instead of stacking infinite rounded rectangles.
- Eliminate generic filler copy (e.g. "Unlock your potential today", "Revolutionize your workflow"). Use direct, purposeful text.

## 2. Dynamic Visual Hierarchy & Polish
- Primary focus element should instantly draw the eye (high contrast hero text, rich CTA, or focal media element).
- Typography contrast: Pair distinct display fonts with highly readable body fonts. Never use the same font weight and size across different visual levels.
- Subtle motion: Use Framer Motion or smooth CSS transitions for hover, tab switches, and modal reveals. Keep durations between 150ms and 300ms.

## 3. Custom Aesthetic Execution
- Define an intentional, brand-specific color palette (e.g. Deep Emerald Green `#0A382C`, Metallic Gold `#D4AF37`, Soft Pearl Cream `#FAF7F2`).
- Use rich visual depth: Subtle inner glows, glassmorphic blurs (`backdrop-blur-md`), ambient shadows, and gilded accent borders.
- Responsive excellence: Mobile views must feel like native mobile apps, with touch-friendly tap targets (minimum 44x44px).
