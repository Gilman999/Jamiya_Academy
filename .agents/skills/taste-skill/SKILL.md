# Taste Skill: Anti-Slop Frontend Craftsmanship

Principles for building memorable web interfaces with exceptional aesthetic taste and polish.

## 1. Distinctive Brand Identity
- Every project must have a signature visual character, avoiding standard template looks.
- Use curated color systems tailored to the brand domain rather than default framework palettes.
- Incorporate custom iconography, theme-matched badges, and contextual decorative elements.

## 2. Typography & Layout Precision
- **Bilingual & Multilingual Respect**: When working with Arabic, Urdu, or RTL languages, ensure proper script fonts (`Amiri`, `Noto Naskh Arabic`) and correct text direction.
- **Header & Section Scale**: Use distinct font weights and sizes to guide eye flow effortlessly down the page.
- **Asymmetric & Grid Balance**: Avoid boring centered-everything layouts; balance content with clean left-aligned text, contextual badges, and dynamic stats containers.

## 3. Tactile Micro-Interactions
- Add reactive state feedback: Hover transforms (`hover:-translate-y-0.5`), active press states, glow borders on focus, and smooth tab switching.
- Micro-badges: Use crisp pill tags (`Online ₹299`, `Females Only 🛡️`, `Verified Certificate 🎓`) with subtle border treatments.
- Smooth Modals & Drawers: Present complex workflows (like admissions or document viewing) in polished overlay dialogs with smooth backdrops.
