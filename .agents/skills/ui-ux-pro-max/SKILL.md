# UI/UX Pro Max Skill

Advanced patterns for rich interactive web applications, student & admin portals, and intuitive dashboards.

## 1. Information Architecture & Navigation
- **Hero & Value Proposition**: Clear identity header, key highlight pills (100% Parda, Female Teachers, Worldwide Access), and direct CTA buttons.
- **Tabbed Course Catalog**: Instant filtering by Category (Islamic, Skills, Languages) and Mode (Online vs Offline) without page reloads.
- **Dedicated Portals**:
  - **Student Dashboard**: Quick access to enrolled courses, live/recorded lectures, downloadable notes, attendance, fee receipts, and official certificates.
  - **Admin Control Center**: Comprehensive management view to publish notices, add courses, upload PDF/Video media, manage student admissions, and verify fee receipts.
  - **Smart Digital Library**: Centralized repository with live search, file category filters (PDF, Video, Audio, Notes), and instant modal previewer.

## 2. Interactive Modals & Forms
- **Multi-step Admission Form**: Clean, mobile-friendly input flow (Student Info -> Course Selection -> Payment Screenshot Upload -> Instant WhatsApp Confirmation).
- **Embedded Document Viewer**: High-usability PDF viewer modal with download options, zoom controls, and print triggers.
- **Live Search & Filter**: Real-time keyword filtering for courses, library books, and notice boards.

## 3. Accessibility & Usability Standards
- High contrast colors compliant with WCAG AA standards.
- Mobile-first responsive layout that scales down gracefully to small smartphone screens.
- Keyboard accessible dialogs, tab loops, and visible focus rings.
